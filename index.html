ABSTRACT

Automated Shrimp Pond Management Through IoT & AI

Smart AquaGuard is an IoT-based automated monitoring and control system designed to enhance shrimp aquaculture management through sustainable, data-driven, and minimized supervised operations.

The system integrates real-time water quality monitoring, sensor-based threshold actuation, and server-driven YOLOv8-based feed and waste detection to optimize environmental conditions and reduce human intervention.

Using an ESP32 microcontroller, built-in camera, WiFi communication, and a cloud server — the system enables automated corrective responses such as aeration, controlled water exchange, and transfer of collected feed waste into a biofloc reservoir for reuse.

THE PROBLEM

Statement of the Problem

Maintaining a clean and well-managed water environment is critical for shrimp survival and production. Current systems fall short in key areas:

⚠️

Existing systems only monitor water quality — they don't automatically correct it

🚫

No detection of uneaten feed waste, leading to ammonia spikes

👤

Manual intervention still required even in intensive farming setups

📉

Poor or fragmented data visualization for farm operators

OUR GOALS

Objectives of the Study

Smart AquaGuard was developed to:

1

Automatically correct water parameters (pH and temperature) using IoT actuators

2

Detect feed waste and shrimp waste in real time using YOLOv8 computer vision

3

Transfer detected feed waste to a biofloc reservoir via suction pump for reuse

4

Transmit all sensor data and detection results to a cloud dashboard via WiFi

5

Compare shrimp growth, mortality, and water stability between automated vs. manual setups

SYSTEM CAPABILITIES

System Features

Click a card to explore each feature

📊

IoT Water Quality Sensors

  • pH sensor — monitors acidity/alkalinity
  • Temperature sensor — tracks thermal conditions
  • ESP32 microcontroller collects and transmits all data via WiFi
📷

YOLOv8 Feed Waste Detection

  • ESP32-CAM captures real-time pond surface images
  • YOLOv8 classifies: clear / turbid / feed waste / shrimp waste
  • Achieves high precision, recall, and F1-score
  • Triggers suction pump when feed waste is detected
  • Processed on cloud server (not on ESP32)
⚙️

Automated Correction System

  • Aerator activated when pH or oxygen is out of range
  • Water exchange pump triggered for temperature correction
  • Suction pump transfers feed waste to biofloc reservoir
  • Cyber-Physical System (CPS) theory applied for automation
  • Reduces manual labor and human intervention
♻️

Biofloc Reservoir Integration

  • Collected feed waste transferred to biofloc reservoir
  • Biofloc converts organic waste into microbial biomass
  • Serves as a nutritious protein source for shrimp
  • Reduces ammonia buildup and water pollution
  • Supports sustainable, low-waste aquaculture
PROCESS FLOW

How Smart AquaGuard Works

🗄️
01

Sensor Data Collection

ESP32 collects pH and temperature readings from IoT sensors placed in the shrimp pond.

📸
02

Camera Feed Capture

ESP32-CAM continuously captures images of the pond surface and transmits them to the cloud server via WiFi.

🧠
03

YOLOv8 Detection

The cloud server runs YOLOv8 to classify the pond surface: clear, turbid, feed waste, or shrimp waste.

⚙️
04

Automated Correction

If parameters exceed thresholds, actuators (aerator, pumps) are triggered automatically to restore ideal conditions.

🔄
05

Biofloc Transfer

Detected feed waste is suctioned and transferred to the biofloc reservoir for reuse as a sustainable shrimp feed source.

💻
06

Dashboard Visualization

All data — sensor readings and detection results — are displayed on the cloud monitoring dashboard.
